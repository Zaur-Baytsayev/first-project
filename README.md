# Шпаргалка markdown


## Выведет текст чуть меньше размером чем 


Курсив *Звездокчи*


Пример **Жирного текста**.


## Заголовок

Заголовки можно создавать с помощью символа #. Чем больше символов тем меньше текст


# Заголовок первого уровня
## Заголовок второго уровня 
### Заголовок третьего уровня
#### Заголовок четвертого уровня
##### Заголовок пятого уровня 
###### Заголовок шестого уровня


## Выделение кода


чтоб выделить код нужно поместить его в тройные кавычки ```.

Пример


```
mkdir my_project
cd my_project
git init
```

Это лишь некоторые функции markdown
